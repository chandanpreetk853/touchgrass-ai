# Contributing to TouchGrass AI 🌿

Thanks for your interest in contributing to TouchGrass AI!

## How to contribute

1. Fork this repository.
2. Create a new branch for your change.
3. Make your changes.
4. Test the project locally.
5. Commit your changes.
6. Open a Pull Request.

## Development

TouchGrass AI uses:

- HTML
- CSS
- JavaScript
- Python
- Ollama
- Gemma 3 1B

Make sure Ollama is running locally and the `gemma3:1b` model is available before testing AI generation.

## Ideas for contributions

Some possible improvements:

- Weather-aware quests
- Better accessibility
- New quest categories
- Achievement system
- Offline improvements
- Better mobile experience

Please keep contributions focused and beginner-friendly.

Thank you for helping improve TouchGrass AI! 🌱
